# Sistema de Gestión Rojas FC

Aplicación web para la gestión administrativa de la Escuela de Fútbol Rojas FC, desarrollada como Trabajo Final Integrador de la Tecnicatura Universitaria en Programación.

## Descripción

El proyecto tiene como objetivo centralizar y optimizar procesos administrativos que actualmente se gestionan mediante planillas de Excel y registros en papel.

La aplicación permitirá gestionar alumnos, responsables, categorías, cuotas, pagos, recibos, eventos e indumentaria, incorporando además herramientas de consulta, reportes y estadísticas.

## Tecnologías

### Frontend
- TypeScript
- React
- Vite
- Tailwind CSS

### Backend
- Java
- Spring Boot
- Spring Data JPA
- API REST

### Base de datos
- MySQL

### Seguridad
- JWT

### Plataforma
- Despliegue cloud mediante PaaS

## Estructura del repositorio

- `frontend/`: aplicación frontend.
- `backend/`: aplicación backend.
- `database/`: scripts y recursos relacionados con la base de datos.
- `docs/`: documentación, diagramas y entregas del proyecto.
